## 📝 Sobre o Projeto
O **CalcWork Soluções** nasceu da vontade de facilitar a rotina de quem lida com números o dia todo. Este projeto é uma suíte de ferramentas desenvolvida para automatizar cálculos de RH que antes eram feitos manualmente. 

Saímos do básico e criamos uma interface "Cyberpunk" que une funcionalidade e estilo. O objetivo foi criar algo que não fosse apenas uma tarefa de escola, mas um software que você realmente teria prazer em usar no trabalho.

## 🛠️ O que ele faz?
O sistema é dividido em três módulos inteligentes:
- **Gestão de Horas Extras:** Calcula o valor real das suas horas trabalhadas. Ele entende que uma hora no domingo vale mais que uma hora na segunda-feira, aplicando as taxas de 50% e 100% automaticamente sobre a base de 200h mensais.
- **Matriz de Crescimento (Growth Matrix):** Um motor de reajuste que aplica aumentos salariais justos. Ele olha para o salário atual e decide se o aumento deve ser de 16%, 13%, 10% ou 5%.
- **Logística e Fretado:** Uma ferramenta para empresas calcularem o custo de transporte da equipe, ajustando o valor por passageiro de acordo com a lotação do veículo.

## 🧠 Desafios e Aprendizados
O maior desafio foi fazer com que o design e a lógica caminhassem juntos. Aprendemos a:
1. **Dominar o Tempo:** Usamos o objeto `Date` para que cada cálculo tenha um "carimbo" de quando foi feito.
2. **Experiência do Usuário:** Adicionamos atalhos como a tecla `ESC` para navegação, pensando em quem precisa de agilidade.
3. **Lógica Condicional:** Criamos regras que permitem ao computador tomar decisões baseadas nos valores inseridos.
